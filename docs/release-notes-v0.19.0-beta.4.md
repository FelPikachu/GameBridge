# GameBridge v0.19.0-beta.4

beta.4 主要固化了兼容环境自动准备、米哈游四款游戏的三类区服路由，以及 Epic 和 SteamGridDB 的已验收流程。

## 主要更新

- 首次打开时自动安装并校验 GameBridge 默认兼容环境。
- 扩展兼容层发现范围，支持已挂载的 Steam 库和外置存储。
- 修复 Epic 游戏无法访问 Steam 客户端库时弹出 `steam.exe` 断言错误的问题。
- 修复米哈游启动器与游戏分盘、硬盘改名和外置存储未连接时的识别问题。
- 固化原神、崩坏3、星穹铁道、绝区零的官服、B 服和国际服已验收启动路线。
- 国际服四款游戏使用相互隔离的 Prefix；国际服《崩坏3》9.0 使用 Steam 管理的 Proton Hotfix。
- 修复区服切换或启用小黄鸭后启动参数被破坏的问题。
- 修复彻底清理后，保留的米哈游游戏因旧 B 服标记无法被新启动器定位的问题。
- 修复 Epic 同步后数量缓存不刷新的逻辑，并支持超过 50 款游戏的分页读取。
- 新增打包脚本和回归保护锁，发布包会检查关键启动脚本的权限。

## 验收情况

- Xbox Ally X（x86_64 SteamOS）已完成米哈游四款游戏、官服 / B 服 / 国际服和国际服小黄鸭路线回归。
- Epic 账号连接、退出后重新登录、下载安装、卸载、云存档和启动参数 / 小黄鸭组合已通过实机验收。
- SteamGridDB 封面、其他素材和已测网络异常处理已通过实机验收。
- Python 回归测试、TypeScript 类型检查和前端构建全部通过。

## 已知待验证项

Steam Deck 首次登录或同步 Epic 后标签显示 `0` 的刷新修复已有自动测试保护，但还需要在曾出现该问题的 Steam Deck 上完成一次首次登录实机确认。
